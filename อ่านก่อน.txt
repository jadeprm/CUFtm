วิธีเปิดการเขียนกลับ (ทำที่ฝั่งพี่ ผมไม่แตะคีย์)
  1. console.cloud.google.com → สร้าง/เลือกโปรเจกต์
  2. APIs & Services → Library → เปิด "Google Sheets API"
  3. Credentials → Create credentials → Service account → ตั้งชื่อ → Done
  4. เปิด service account นั้น → Keys → Add key → Create new key → JSON
  5. ในไฟล์ JSON เอาค่า client_email กับ private_key
  6. แชร์ชีตรายชื่อให้ client_email นั้น เป็น Editor
     (ลิงก์สาธารณะยังเป็น Viewer เหมือนเดิม ไม่ได้เปิดให้ใครแก้ได้)
  7. Vercel → Settings → Environment Variables
       GOOGLE_SA_EMAIL        = client_email
       GOOGLE_SA_PRIVATE_KEY  = private_key ทั้งก้อน รวม BEGIN/END
  8. Redeploy → คำเตือนสีเหลืองบนหน้าแอดมินจะหายไป
