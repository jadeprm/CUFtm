1. Overview (English)

CUFTM (Chula Fair Tasks) is an internal task, meeting, and document approval tracker for the Chulalongkorn University Fair organizing committee. We collect only the account information needed for committee collaboration: username, display name, department, position, verified email address, and tasks/events/documents created inside the app.

2. Google API Data Accessed & How We Use It

When a user explicitly connects their Google account in CUFTM, we request only the minimum scopes needed for user-facing features:

  • Google Calendar (https://www.googleapis.com/auth/calendar.events): Reads busy time ranges to prevent scheduling conflicts when arranging committee meetings or office hours (private event titles are never shown to other users), and creates/updates/removes CUFTM appointments and meetings on the user's primary calendar when enabled.
  • Google Tasks (https://www.googleapis.com/auth/tasks): Performs two-way synchronization between the user's assigned CUFTM tasks and a dedicated "CUFTM · งานจุฬาฯแฟร์" task list in their Google Tasks so they can view and complete committee tasks via Google Workspace and Gemini.
  • Google Drive (https://www.googleapis.com/auth/drive.file): Used exclusively by committee administrators to archive finalized, signed PDF documents into a dedicated committee folder created by CUFTM. This scope cannot read or access any other files in the user's Google Drive.

3. Google API Services User Data Policy (Limited Use Disclosure)

CUFTM's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • We do not sell, rent, or transfer Google user data to third parties or advertisers.
  • We do not use Google Workspace API data to develop, improve, or train generalized AI/ML models.
  • OAuth refresh tokens are encrypted at rest using AES-256-GCM.

4. Data Retention, Revocation & Deletion

Users may disconnect their Google account at any time from the CUFTM Schedule page (which revokes and deletes the stored OAuth token) or via Google Account Permissions. To request deletion of your CUFTM account or data, email chulafair.sgcu@gmail.com.

นโยบายความเป็นส่วนตัว (ภาษาไทย)

CUFTM เป็นระบบติดตามงาน การประชุม และเอกสารอนุมัติภายในของคณะกรรมการงานจุฬาฯแฟร์ จัดเก็บเฉพาะข้อมูลที่จำเป็นต่อการทำงาน ได้แก่ ชื่อผู้ใช้ ชื่อแสดง ฝ่าย ตำแหน่ง อีเมลยืนยันตัวตน และข้อมูลงาน/เอกสารในระบบ

  • Google Calendar (calendar.events): อ่านช่วงเวลาไม่ว่างเพื่อช่วยนัดประชุม (ไม่แสดงชื่อนัดส่วนตัวให้ผู้อื่นเห็น) และเพิ่มนัดหมาย/ประชุมลงปฏิทินของผู้ใช้เมื่อเปิดใช้งาน
  • Google Tasks (tasks): ซิงก์งานสองทางกับรายการ "CUFTM · งานจุฬาฯแฟร์" ใน Google Tasks เพื่อให้ใช้งานร่วมกับ Gemini และ Google Workspace
  • Google Drive (drive.file): ใช้โดยผู้ดูแลระบบเพื่อเก็บเอกสาร PDF ที่ลงนามเสร็จแล้วลงในโฟลเดอร์ที่ระบบสร้างขึ้นเท่านั้น ไม่เข้าถึงไฟล์อื่นใน Drive

การใช้งานข้อมูลจาก Google APIs ปฏิบัติตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use อย่างเคร่งครัด โทเค็นเชื่อมต่อถูกเข้ารหัสด้วย AES-256-GCM ไม่นำไปขาย โฆษณา หรือฝึกโมเดล AI และสามารถยกเลิกการเชื่อมต่อได้ทุกเมื่อจากหน้าปฏิทินในระบบ หรือติดต่อ chulafair.sgcu@gmail.com
